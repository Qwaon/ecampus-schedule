# Расписание eCampus — PWA

Статический React/Vite фронтенд для просмотра личного расписания и
сессии (экзамены/зачёты) из `schedule.json`. Дизайн скопирован с
проекта `stgmu_110` (Apple HIG стиль). Тема (светлая/тёмная) следует
системной настройке автоматически, переключателя в приложении нет.

Три вкладки: **Главная** (сегодня), **Расписание** (по неделям),
**Сессия** (экзамены/зачёты по семестрам, текущий семестр наверху,
прошедшие — под спойлером).

## Уведомления перед парами

Кнопка-колокольчик в шапке включает локальные уведомления браузера за
15 минут до начала каждой пары (`src/hooks/useLessonNotifications.js`).

Важное ограничение: это не push с сервера, а таймер внутри самой
страницы — уведомления сработают только пока PWA открыто (хотя бы в
фоновой вкладке/за экраном). На iOS Safari нет способа получать эти
уведомления, если приложение полностью закрыто — Apple не даёт
статичным PWA будить себя по расписанию без backend push-сервера
(Web Push на iOS 16.4+ поддерживается, но требует сервера, который
инициирует отправку). Такого сервера в этом проекте нет.

## Обновление данных

`public/schedule.json` — статический файл, который коммитится в
репозиторий. После каждого запуска `fetch_schedule.py` +
`parse_schedule.py` в основном проекте (`../fetch_schedule.py`,
`../parse_schedule.py`) копируй свежий `schedule.json` сюда и делай
`git push` — GitHub Actions пересоберёт и задеплоит сайт на GitHub
Pages автоматически.

```bash
cp ../schedule.json public/schedule.json
git add public/schedule.json
git commit -m "update schedule"
git push
```


## Деплой

Пуш в `main` триггерит `.github/workflows/deploy.yml`, который
собирает проект и публикует `dist/` на GitHub Pages. Репозиторий
приватный (в `schedule.json` личные данные — ФИО преподавателей,
оценки), поэтому GitHub Pages из приватного репо требует GitHub
Pro/Team/EDU.
